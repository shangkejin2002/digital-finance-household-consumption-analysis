# データと作成手順

## 使用データ

本研究では、以下のデータを使用しました。

- China Family Panel Studies（CFPS）2014・2018年の家計経済データ
- 北京大学デジタル金融研究センターの省別デジタル金融包摂指数（PKU-DFIIC）2014年

CFPSの利用条件とプライバシー保護のため、個票データと作成済み分析データは公開していません。

## 最終分析サンプル

| 項目 | 件数 |
| --- | ---: |
| 世帯数 | 7,344 |
| 対象となる省級地域 | 27 |
| ロング形式の最大観測数 | 14,688 |
| 回帰に使用された観測数 | 14,686 |

2018年のエンゲル係数が欠損している2観測は、回帰時に除外されます。DFIデータ自体は全国31省級地域を含みますが、最終分析サンプルに含まれる地域は27です。

## 確認できたデータ整理の流れ

1. CFPS 2014・2018年の家計経済ファイルから、世帯ID、地域、食品支出、総消費支出を抽出する。
2. CFPSの特殊欠損値を欠損として扱い、年次間で変数名と地域コードを統一する。
3. 調査年をまたいで世帯を対応付け、2014年と2018年を含むワイド形式の分析表を作成する。
4. `食品支出 / 総消費支出` により各年のエンゲル係数を作成する。
5. 省級地域をキーとして2014年のDFI指数を結合する。
6. RでDFIのサンプル中央値を計算し、中央値以上を高DFI地域とする。
7. データ品質を確認したうえで、原論文仕様と感度分析を分けて推定する。

最終データにおけるDFI中央値は **173.82** です。公開Rコードでは、入力ファイルに保存された旧 `Treat_p` 列を使用せず、この中央値ルールから再作成します。

## 公開Stataコードの位置付け

[`../code/data_preparation.do`](../code/data_preparation.do) は、実際の研究で行った処理を説明するための簡略版です。

CFPSでは、調査期間中の世帯分割などにより共通世帯ID `fid10` が原始ファイル内で重複します。確認した原始ファイルでは、2014年は13,946行、2018年は14,218行であり、`fid10` は一意ではありません。そのため、公開コードだけで原始ファイルから最終7,344世帯を完全に再作成することはできません。

この制約を明示するため、公開Stataコードでは未確認の世帯選択方法を追加せず、確認できた処理と追加確認が必要な箇所をコメントで区別しています。

## 分析データの変数

Rスクリプトは、次の構造を持つExcelファイルを想定します。

```text
data/analysis_data.xlsx
└── Sheet1
```

| 変数 | 内容 |
| --- | --- |
| `ID` | 2014年と2018年を対応させる世帯ID |
| `Province` | 省級地域。標準誤差のクラスタ単位にも使用 |
| `DFI` | 2014年時点の省別デジタル金融包摂指数 |
| `FOOD_2014`, `FOOD_2018` | 各年の食品支出 |
| `TOTAL_2014`, `TOTAL_2018` | 各年の総消費支出 |
| `Engel_2014`, `Engel_2018` | 食品支出を総消費支出で割った比率 |

`Treat_p` はR側で作成するため、入力ファイルの必須変数ではありません。

## データ品質の確認

最終分析データには、エンゲル係数が0〜1の範囲を超える観測が含まれます。

| 年 | 0〜1の範囲を超える観測 |
| --- | ---: |
| 2014 | 117 |
| 2018 | 131 |

公開Rコードでは、次の2種類を明確に分けています。

- **原論文仕様**：卒業論文と同じ分析対象を用い、報告済み結果を再現する。
- **感度分析**：両年のエンゲル係数が0〜1の7,098世帯に限定し、結果がデータ範囲の確認にどの程度敏感かを調べる。

感度分析は原論文の結果を置き換えるものではありません。異常値の発生理由と当初の処理方針を完全には追跡できないため、両方の結果を示し、因果的な断定を避けています。
