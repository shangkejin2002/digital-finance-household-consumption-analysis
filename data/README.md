# Data and Preparation

## データの取り扱い

本研究では CFPS 2014・2018 年家計データと、北京大学デジタル金融研究センターの省別デジタル金融包摂指数を使用しました。CFPS の利用条件とプライバシー保護のため、個票データと作成済み分析データは本リポジトリに含めていません。

## データ整理の流れ

1. 各年の CFPS 家計経済データから、共通世帯 ID、地域、食品支出、総消費支出を抽出する。
2. CFPS で欠損・非該当等を表す負の特殊コードを欠損値として処理する。
3. 2014 年と 2018 年で変数名を統一し、共通世帯 ID `fid10` により対応付ける。
4. 両年で観測できる世帯を分析対象とし、2 時点のパネルデータを作成する。
5. `食品支出 / 総消費支出` により各年のエンゲル係数を作成する。
6. 省をキーとして 2014 年の DFI 指数を結合する。
7. 年次、政策後ダミー、DFI の高低を表す変数を作成し、R で分析できる形式に整える。

Stata での処理手順は [`../code/data_preparation.do`](../code/data_preparation.do) にまとめています。

## 最終分析データ

R スクリプトは、次のファイルを入力として使用します。

```text
data/analysis_data.xlsx
```

シート名は `Sheet1`、1 行は 1 世帯です。主な変数は次のとおりです。

| 変数 | 内容 |
| --- | --- |
| `ID` | 2014 年と 2018 年を対応させる世帯 ID |
| `Province` | 省・地域 |
| `DFI` | 2014 年時点の省別デジタル金融包摂指数 |
| `Treat_p` | 高 DFI 地域を 1、低 DFI 地域を 0 とする変数 |
| `FOOD_2014` | 2014 年の食品支出 |
| `FOOD_2018` | 2018 年の食品支出 |
| `TOTAL_2014` | 2014 年の総消費支出 |
| `TOTAL_2018` | 2018 年の総消費支出 |
| `Engel_2014` | 2014 年のエンゲル係数 |
| `Engel_2018` | 2018 年のエンゲル係数 |

分析データは `.gitignore` の対象としており、誤って公開されない設定にしています。
