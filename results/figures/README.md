# 図の説明

このフォルダには、[`../../code/analysis.R`](../../code/analysis.R) が実データから作成する2枚の図を保存します。

## `engel_change_by_dfi_group.png`

両年のエンゲル係数が0〜1の世帯を対象に、高DFI地域と低DFI地域の平均値を2014年・2018年で比較した記述統計です。エラーバーは95%信頼区間です。

## `model_sensitivity.png`

原論文と同じデータを用いた推定と、両年のエンゲル係数が0〜1の世帯に限定した感度分析を比較します。連続DFIモデルはDFIが10ポイント高い場合の変化、高・低DFIモデルは2群間の変化差をパーセントポイントで表示しています。

いずれの図も因果効果を単独で証明するものではありません。
